# Privacy Policy

HushHush is a browser extension that runs locally in Chrome.

## Data stored on your device

- Mute phrases and interest preferences (`chrome.storage`)
- Optional API key and provider settings if you enable AI mode

## Network

- Keyword filtering does not send post content anywhere
- If you enable AI mode, post text is sent only to the LLM provider you configure (for example Groq, OpenAI, or OpenRouter)

## Not collected

- No analytics
- No accounts
- No HushHush backend that stores your timeline

Contact the repository maintainer for privacy questions.
